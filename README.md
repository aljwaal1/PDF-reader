# PDF Reader

تطبيق Flutter للـ Android وiPhone يركز على قراءة كتب PDF الإنجليزية صوتيًا وترجمتها إلى العربية مع متابعة موضع القراءة.

## المزايا الحالية

- فتح ملفات PDF من الجهاز.
- عرض الكتاب وحفظ آخر صفحة وموضع القراءة داخل الصفحة.
- قراءة النص الإنجليزي عبر Text-to-Speech مع متابعة الكلمة والجملة الحالية.
- ترجمة إنجليزي → عربي باستخدام ML Kit بعد تنزيل نماذج اللغة أول مرة.
- ترجمة الجملة أثناء القراءة وتراكم الترجمة حتى تصبح الصفحة كاملة.
- انتقال تلقائي اختياري إلى الصفحة التالية ومتابعة القراءة.
- حفظ الترجمات وموضع القراءة للعودة إليهما لاحقًا.
- خمس طرق عرض يختار بينها المستخدم:
  - PDF فقط.
  - الترجمة فقط.
  - الترجمة أسفل الصفحة.
  - PDF والترجمة جنبًا إلى جنب.
  - لوحة ترجمة قابلة للسحب من أسفل الشاشة.
- تغيير سرعة القراءة مع الاستمرار من الموضع الحالي.

## التقنية

- Flutter: قاعدة كود واحدة لـ Android وiOS.
- pdfrx: عرض PDF واستخراج نص الصفحة.
- flutter_tts: القراءة الصوتية.
- google_mlkit_translation: ترجمة محلية على Android وiOS.
- shared_preferences: حفظ الكتاب والصفحة وموضع القراءة والترجمات.

## ملاحظة

النسخة الحالية تستخرج النص من ملفات PDF النصية. دعم الكتب الممسوحة ضوئيًا OCR يمكن إضافته لاحقًا دون تغيير منطق شاشة القراءة.
