# PDF Reader

تطبيق Flutter للـ Android وiPhone يركز على وظيفتين أساسيتين: قراءة كتب PDF الإنجليزية صوتيًا، وترجمة الصفحة الحالية إلى العربية.

## النسخة الأولى

- فتح ملفات PDF من الجهاز.
- عرض الكتاب وحفظ آخر صفحة.
- قراءة النص الإنجليزي في الصفحة الحالية عبر Text-to-Speech.
- ترجمة إنجليزي → عربي على الجهاز باستخدام ML Kit بعد تنزيل نماذج اللغة أول مرة.
- حفظ ترجمة الصفحات في الذاكرة أثناء جلسة القراءة.
- خمس طرق عرض يختار بينها المستخدم:
  - PDF فقط.
  - الترجمة فقط.
  - الترجمة أسفل الصفحة.
  - PDF والترجمة جنبًا إلى جنب.
  - لوحة ترجمة قابلة للسحب من أسفل الشاشة.
- تغيير سرعة القراءة.

## التقنية

- Flutter: قاعدة كود واحدة لـ Android وiOS.
- pdfrx: عرض PDF واستخراج نص الصفحة.
- flutter_tts: القراءة الصوتية.
- google_mlkit_translation: ترجمة محلية على Android وiOS.
- shared_preferences: حفظ آخر كتاب وآخر صفحة.

## ملاحظة

النسخة الحالية تستخرج النص من ملفات PDF النصية. دعم الكتب الممسوحة ضوئيًا OCR سيضاف لاحقًا دون تغيير منطق شاشة القراءة.
